# copy-check — живой русский для пользовательского текста

Проект русскоязычный: подписи и подсказки в `templates/**`, тексты в `report.py`,
названия/описания и комментарии к упражнениям, сообщения flash. Цель — живой текст, а не стерильный.

## Область применения (строго)
- Только видимый пользователю текст: строки в HTML-шаблонах, тексты отчётов, сообщения.
- НЕ трогать: код и идентификаторы, комментарии в коде, `docs/**`, `AGENTS.md`/`CLAUDE.md`,
  commit-сообщения (они остаются английскими и техническими), содержимое JSON-данных каталога.

## Быстрый чек-лист (по приоритету)
1. **Канцелярит** → верни глаголы: «осуществление оптимизации» → «оптимизировали».
2. **Кальки с английского**: «стоит отметить, что», «важно понимать, что», «является» > раза на 500 слов.
3. **Пустые открытия**: «В современном мире…», «В условиях…» — удалить, начать с сути.
4. **Раздувание значимости**: «играет ключевую роль», «невозможно переоценить» → показать факт.
5. **Формульные выводы**: «Таким образом», «Подводя итог» — убрать, если можно удалить без потери смысла.
6. **Правило трёх** из синонимов: «важный, значительный и ключевой» → оставить один.
7. **Однообразие ритма**: чередовать короткие и длинные фразы; разговорная частица к месту.
8. **Однообразие зачинов** пунктов списка (все с одной конструкции) — развести.

## Правила безопасности (факт-замок)
- Не выдумывать конкретику (цифры, кейсы, имена), которой нет в исходнике.
- Не менять смысл, числа, единицы и названия упражнений.
- Сохранять существующую живую лексику: не заменять разговорное на нейтральное.
- В интерфейсе быть лаконичным: это подписи, а не статья — не раздувать ради «живости».

## Как работать
1. Определи тип текста: `UI-подпись` (минимальная правка), `отчёт/сообщение` (средняя).
2. Найди конкретные срабатывания из чек-листа (не переписывай то, что уже хорошо).
3. Предложи правки парами «было → стало», сгруппированно по файлу.
4. Правки вносишь только после подтверждения пользователя; затем прогони `pytest` (тексты
   отчётов покрыты `tests/test_report.py`).

## Полная версия
Для глубокой правки больших текстов можно поставить полноценный скилл `humanizer-ru`
(72 правила + сканер) на DEV-стенде как плагин Claude Code; в репозиторий он не вендорится
(98 КБ + eval-набор). Этот `copy-check` — лёгкая локальная версия под задачи IronMind.
