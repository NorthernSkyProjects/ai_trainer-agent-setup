# bar.md — измеримые механизмы референса

**Референс:** текущий `/next/plan` (Kachlog, shadcn base-nova).
**Дата:** 2026-11-14.

Это не «нравится/не нравится», а проверяемые механизмы. Каждый пункт можно измерить
или проверить по скриншоту/коду.

| # | Механизм | Как проверяем | Порог |
|---|---|---|---|
| M1 | Today-карточка доминирует на первом экране | высота карточки / высота viewport (1440×900) | ≥ 25% |
| M2 | Один primary CTA на смысловой блок | визуальный поиск залитых кнопок | ≤ 1 на блок, ≤ 2 на экран |
| M3 | Все числа — mono/tabular | `font-mono tabular-nums` у весов, повторов, % | 100% чисел |
| M4 | Teal только прогресс/успех | поиск `chart-*` в компонентах | нет teal-текста на белом < 4.5:1 |
| M5 | Плотная навигация без визуального шума | sidebar: 5 пунктов + подпункты; mobile: 5 табов | активный — заливка/soft, не цветной акцент |
| M6 | Карточки — ring 1px + радиус 10px, без тяжёлых теней | CSS/скриншот | ring есть у всех карточек; тень только у sheet/toast |
| M7 | Mobile: тач-цели и safe-area | CSS `min-h-11`, `padding-bottom: env(safe-area-inset-bottom)` | CTA ≥44 px; tab bar не перекрывает контент |
| M8 | AI-состояние имеет имя и выход | есть `pending`, `error`, «Отмена»/«Повторить» | ни одного «вечного спиннера» |

## Как оценивал критик

1. **Brief** — совпадает ли результат с заданием и DESIGN.md.
2. **System** — совпадают ли токены, типографика, отступы и компоненты с `/next/plan`.
3. **Craft** — слепое сравнение с референс-скриншотом: иерархия, ритм, края, mobile.

Вердикт бинарный: **pass** или **fail** по каждому механизму. Выход — когда все pass.
