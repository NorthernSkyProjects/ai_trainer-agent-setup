## Анти-паттерны UX

Короткий список того, что не копируем, даже если это работает у конкурентов.

| Анти-паттерн | Где встречается | Почему не берём |
|---|---|---|
| Соцлента и лидерборды как обязательный слой | Hevy, Boostcamp | шум и сравнение отвлекают от лога; Kachlog оставляет только шеринг результата |
| «Чёрный ящик» рекомендаций | Fitbod, RP Hypertrophy | пользователь не понимает, почему изменился план; нужен ответ «почему» одной строкой |
| Жёсткая привязка мезоцикла к понедельнику | RP Hypertrophy | ломает гибкий график; в Kachlog день недели настраивается |
| Платная стена на базовый лог или план | Fitbod, RP Hypertrophy | барьер до «aha» — первой завершённой тренировки |
| Перегруз RIR и periodization на первом экране | Alpha Progression, RP Hypertrophy | новичок бросает настройку; в Kachlog это вторичный слой |
| Ложная точность recovery и готовности | Fitbod | нет данных о сне и HRV; лучше честная «разгрузка/усталость» |
| Пустые состояния без одного действия | многие | тупик; у Kachlog один CTA и объяснение |
| Визуальные клоны и чужие бренды | — | теряется идентичность; копируем паттерн, а не бренд |

## Разбор по продуктам

### 1. Hevy

**Позиционирование:** «#1 workout tracker», простой лог + социальная мотивация.
**Сильные стороны:**
- быстрый лог: значения прошлой тренировки уже подставлены;
- понятная структура: Routines → Workout → Exercise → Set;
- PR/1RM, объём, графики по упражнениям, календарь и streak;
- бесплатный базовый лог без рекламы, Pro снимает лимиты;
- Apple Watch/Wear OS, офлайн, экспорт CSV.

**Слабые стороны / что не копируем:**
- соцлента и лидерборды — не наш scope;
- визуально нейтральный, «ещё один трекер»; нам нужна своя идентичность внутри shadcn;
- AI-план только в Pro и без акцента на ограничениях здоровья.

**UX-паттерны для Kachlog:**
1. «В прошлый раз» прямо в карточке упражнения.
2. Автостарт rest timer после подхода.
3. PR-бейдж в момент рекорда.
4. Streak/календарь как мягкая мотивация.

**Источники:** hevyapp.com/features, help.hevyapp.com (2026 Features Guide), App Store.

### 2. Fitbod

**Позиционирование:** AI-тренер, который строит каждую тренировку под оборудование, цель,
уровень и восстановление.
**Сильные стороны:**
- recovery-модель: у каждой мышцы 0–100%, свежие мышцы в приоритете;
- упражнения подбираются по эффективности, оборудованию и обратной связи;
- вес/повторы/подходы меняются по логу, есть mStrength и нелинейная периодизация;
- heat map восстановления, интеграции Apple Health/Health Connect/Strava;
- 1000+ упражнений с видео.

**Слабые стороны / что не копируем:**
- нет недельного планировщика в привычном смысле (saved workouts вместо программы);
- recovery-модель не читает сон/HRV, но выглядит «умнее», чем есть;
- подписка без бесплатного тарифа;
- объяснение решений слабое: пользователь видит результат, но не логику.

**UX-паттерны для Kachlog:**
1. «Почему это упражнение» — короткое объяснение под карточкой.
2. Recovery/усталость как визуальный слой, но без ложной точности.
3. Автоматическая прогрессия с возможностью отменить.
4. Экран «Body» с heat map — вдохновение для прогресса, не для копирования.

**Источники:** help.fitbod.me «How Fitbod Creates Your Workout», fitbod.me, Google Play, Gript review (2026).

### 3. Alpha Progression

**Позиционирование:** генератор плана + точные рекомендации веса/повторов на каждый подход.
**Сильные стороны:**
- план по цели, опыту, оборудованию, частоте и длительности;
- выбор сплита (full body, upper/lower, PPL) или автоматический;
- рекомендации на каждый рабочий подход с учётом прошлых тренировок и доступных весов;
- RIR, периодизация, делоады, plate/warm-up калькуляторы;
- 795 упражнений с реальными видео, offline logging, CSV.

**Слабые стороны / что не копируем:**
- Pro-стена на генератор и рекомендации;
- много настроек (RIR, periodization) может перегружать новичка;
- визуально функционально, без сильного характера.

**UX-паттерны для Kachlog:**
1. «Следующий вес слишком большой — добавь повтор» вместо резкого прыжка.
2. RIR как необязательный слой, не обязательное поле.
3. План полностью редактируемый после генерации.
4. Несколько «залов» с разным оборудованием — идея на будущее.

**Источники:** alphaprogression.com/en, /fact-sheet, блог о plan generator (2026-09-17).

### 4. RP Hypertrophy

**Позиционирование:** мезоциклы и авторегуляция объёма по субъективной обратной связи.
**Сильные стороны:**
- 45+ готовых программ и meso builder;
- авторегуляция: pump/soreness/workload → больше/меньше подходов;
- прогрессия веса/повторов по неделям, делоад в конце мезоцикла;
- сильная методология (MV/MEV/MAV/MRV), доверие продвинутых.

**Слабые стороны / что не копируем:**
- жёсткий старт мезоцикла по понедельникам;
- маленькая библиотека упражнений и ограниченные замены;
- нет календаря истории и кардио;
- высокая цена, нет free trial;
- сложный язык для новичка.

**UX-паттерны для Kachlog:**
1. Чек-ин после тренировки: «как ощущения?» → влияние на следующую неделю.
2. Делоад как явная фаза с бейджем.
3. Объяснение, почему объём изменился.
4. Не копируем жёсткую привязку к понедельнику: у Kachlog день недели настраивается.

**Источники:** rpstrength.com/pages/hypertrophy-app, help.rpstrength.com (Progressions, 2026-09-30), Mesostrength review (2026-09-22).

### 5. Strong

**Позиционирование:** самый простой и быстрый логгер, «делает работу и не мешает».
**Сильные стороны:**
- минималистичный интерфейс, крупные контролы;
- шаблоны, supersets, drop sets, warm-up/failure-теги;
- rest timer, plate/warm-up калькуляторы;
- 1RM, объём, графики, Apple Health, CSV.

**Слабые стороны / что не копируем:**
- не строит программу и не рекомендует прогрессию;
- 2026-обновления косметические, нет AI;
- бесплатная версия ограничена 3 шаблонами.

**UX-паттерны для Kachlog:**
1. Один экран = одна задача: тренировка не тонет в навигации.
2. Крупные степперы веса/повторов, минимум полей.
3. Теги подхода (разминка/дроп/отказ) как вторичный слой.
4. «Ничего лишнего» — принцип для экрана тренировки.

**Источники:** strong.app, Google Play (обновление 2026-11-11), App Store, Sensai review (2026).

### 6. Boostcamp

**Позиционирование:** библиотека программ + полноценный трекер + auto progression.
**Сильные стороны:**
- 14 000+ программ, 130+ от тренеров, фильтры по цели/уровню/оборудованию;
- RPE, rest timer, plate calculator, swap exercise с сохранением предписания;
- PR-бейджи в реальном времени, Strength Score, Weekly Report;
- muscle tracker (heatmap/radar/table);
- personalized program и auto progression в Pro.

**Слабые стороны / что не копируем:**
- программы — главный вход, а не персональный план под здоровье;
- много социальных и соревновательных слоёв;
- визуально плотно, не для новичка.

**UX-паттерны для Kachlog:**
1. Замена упражнения «на один раз» vs «до конца цикла».
2. Weekly Report как короткий итог недели.
3. Strength Score / понятная одна цифра прогресса.
4. Пресеты программ с фильтрами — идея для конструктора.

**Источники:** boostcamp.app/features, /workout-tracker, /features/program-library (обновлено октябрь 2026).

| Чек-ин после тренировки | RP | Один короткий вопрос, не форма |
| Weekly Report | Boostcamp, Hevy | Уже есть дебриф; сокращаем до 3 выводов |
| Делоад как явная фаза | RP, Alpha | Бейдж «Разгрузка» + объяснение |
| Пустые состояния с одним действием | все | Один CTA, без тупиков |

## Что не копируем в бренде и контенте

- чужие программы, тексты, логотипы и фото;
- визуальные клоны: цвета, шрифты и композицию конкурентов;
- фирменный стиль конкурентов целиком;
- чужие экраны и иллюстрации.

## Дифференциация Kachlog

1. **Безопасность как фича №1:** ограничения здоровья/возраста/оборудования влияют на план
   детерминированно, а не «надеемся на промпт».
2. **Русский язык и локальный контекст:** зал/дом/улица, привычные названия упражнений.
3. **PWA + офлайн:** тренировка в подвале зала не теряется.
4. **Объяснимость:** «Память тренера», причины изменений, базовый разбор при сбое ИИ.
5. **Честная бесплатность:** базовый лог и план не за платной стеной (текущая модель).

## Вывод для визуальной концепции

Конкуренты задают **поведение**, а не внешний вид. Визуально Kachlog остаётся в текущей
shadcn-системе `/next/plan`: stone-палитра, Inter + Geist Mono, teal только для прогресса.
Из конкурентов берём плотность и ясность Strong, скорость лога Hevy, объяснимость Alpha Progression,
честные состояния Fitbod/RP и недельный итог Boostcamp.
