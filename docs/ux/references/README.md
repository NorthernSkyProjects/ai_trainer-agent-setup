# Референсы: как снимали брендинг

**Дата:** 2026-11-14

## Метод

Брендинг снят вручную по **схеме Firecrawl branding**, которую возвращает
`scrape(url, formats=["branding"])`:

```json
{
  "colorScheme": "light|dark",
  "colors": { "primary": "...", "background": "...", "text": "..." },
  "typography": { "fontFamilies": { "heading": "...", "body": "..." } },
  "spacing": { "baseUnit": 8, "borderRadius": "..." },
  "components": { "buttonPrimary": { ... } },
  "images": { "logo": "..." }
}
```

Источники: HTML/CSS главных страниц, публичные design-гайды, визуальная проверка.
Для Fitbod сайт отдаёт 403 — брендинг не снимали, оставили только UX-разбор.

## Что делаем с этими файлами

- **Не** используем палитры/шрифты референсов в Kachlog.
- Используем **структуру и паттерны**: плотность, иерархия, поведение компонентов.
- В DESIGN.md ссылаемся на них как на источники вдохновения, а не как на токены продукта.

## Файлы

- `linear-branding.json` — структура, плотность, спокойная система.
- `hevy-branding.json` — доменные паттерны тренировочного лога.
- `fitbod-ux.md` — UX-разбор без брендинга (сайт блокирует запросы).
