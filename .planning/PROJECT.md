# Kachlog

## What This Is

Kachlog (formerly IronMind) is a Flask web app for gym workout tracking with AI-generated training plans (Google Gemini). Users fill in a profile (age, health conditions, equipment, goals, limitations), then either get a plan generated by AI or build one manually in a constructor. They log workouts, see history and stats, and share reports (e.g. via Telegram). The product name comes from `APP_NAME` in `config.py` and is never hard-coded. The UI is in Russian.

## Core Value

A user gets a safe, personalised workout plan (AI or manual) and can reliably log and review their training. Plans must never include exercises forbidden by the user's limitations, age or health conditions.

## Context

- Brownfield: codebase already mapped in `.planning/codebase/` (baseline commit `2a564d8`).
- Two servers, one repo: PROD (Amsterdam, `iitrainer.duckdns.org`) and DEV (Finland). Push to `main` deploys to PROD, so only green code (pytest + ruff) is pushed.
- Routes live in blueprints under `bp/`; `app.py` only wires the app. AI facade in `ai_generator.py` re-exports `ai_safety`, `ai_prompts`, `ai_normalize`, `ai_analysis`, `ai_plan_gen`; tests patch the name in the module that uses it.
- Project docs are in Russian; code and commit messages are in English; UI text is in Russian.

## Constraints

- **Tech stack**: Python 3.10, Flask, SQLAlchemy/SQLite (WAL), Redis/RQ, vanilla JS — existing and deployed
- **Quality gate**: `pytest` and `ruff check .` must pass before every commit; CI blocks deploy on red
- **Deploy**: any push to `main` goes to PROD — no force pushes, no touching prod services
- **Frontend**: no inline `<style>`/`onclick`; CSRF on all requests; Chart.js vendored, no CDN
- **Module size**: `tests/test_module_sizes.py` enforces a 600-line ceiling
- **Secrets**: `.env`, `/etc/ai_trainer.env`, `instance/` are never read or committed
