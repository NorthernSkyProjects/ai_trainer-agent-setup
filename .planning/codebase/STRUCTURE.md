## Directory Purposes

**`bp/`:**
- Purpose: HTTP route modules, one Blueprint per feature.
- Contains: `auth.py`, `ops.py`, `profile.py`, `stats.py`, `onboarding.py`, `constructor.py`, `plan.py`, `workout.py`, `main.py`, `history.py`, `legal.py`, `telegram.py`, plus empty `__init__.py`.
- Key files: `bp/plan.py` (orchestration `perform_generation`, `perform_regeneration`, `save_workout_plan`, job status), `bp/workout.py` (`/workout/today`, exercise APIs), `bp/main.py` (`/`, `/sw.js`).
- Each module is under 600 lines (largest: `bp/stats.py` ~570, `bp/workout.py` ~566, `bp/plan.py` ~561).

**`templates/`:**
- Purpose: server-rendered HTML.
- Contains: page templates (`my_plan.html`, `workout.html`, `history.html`, `stats.html`, `profile.html`, `constructor.html`, `login.html`, `register.html`, `share.html`, `error.html`, ...), partials prefixed with `_` (`_analysis_block.html`, `_exercise_media.html`, `_rest_timers.html`, `_wheel.html`, `_history_card.html`, `_debrief_card.html`, ...), and `onboarding/`.
- Key files: `templates/base.html` (layout, nav, theme attribute, flash region, share modal).

**`static/`:**
- Purpose: browser assets.
- Contains: `style.css` (CSS variables, `[data-theme="dark"]`), `ui.js` (toast, CSRF helper, delegated listeners, PWA init), `sw.js` (service worker, served at `/sw.js`), `manifest.json`, `offline.html`, `50x.html`, feature scripts (`workout_*.js`, `wheel.js`, `load.js`, `heatmap.js`, `debrief.js`), `pages/*.js` (per-page modules: onboarding steps, constructor, history, my_plan, profile, stats).
- Vendored: `vendor/chart.umd.min.js`. Fonts are local woff2.

**`migrations/`:**
- Purpose: Alembic schema history.
- Contains: `env.py`, `alembic.ini`, `script.py.mako`, `versions/*.py` (baseline `95cab703df08_baseline_schema.py` and later revisions).
- Generated: `versions/` is generated by `flask --app app db migrate`; do not hand-write.

**`tests/`:**
- Purpose: pytest suite. `tests/conftest.py` sets env vars and a temp SQLite DB before importing `app`; keep that order.
- Contains: `test_<area>.py` files (for example `test_workout.py`, `test_ai_pipeline.py`, `test_module_sizes.py`, `test_validation.py`), shared fixtures `conftest.py`, AI stubs in `ai_fixtures.py`.
- `tests/e2e/`: Playwright tests marked `e2e`, run with `pytest -m e2e tests/e2e`, outside the CI gate.

**`data/`:**
- Purpose: static catalog and seed data.
- Key files: `ru_catalog.json` (curated RU names), `exercises_ru.json` (Gemini-translated overlay), `exercises_seed.json` (built seed, rebuilt by `scripts/build_exercise_seed.py`), `exercise_media_manifest.json`, `plan_eval/profiles.json`.

**`scripts/`:**
- Purpose: one-off and operational scripts (not imported by the app).
- Key files: `build_exercise_seed.py`, `translate_exercise_seed.py`, `import_dataset_media.py`, `generate_exercise_images.py`, `backup_db.py`, `alerts.py`, `plan_eval.py`, `seed_test_user.py`, `wait_healthy.py`, `visual_diff.py`, `ui_screens.py`, `build_pwa_icons.py`, `nightly_e2e.sh`.
- `scripts/legacy/` is an archive; do not add code there.

**`deploy/`:**
- Purpose: production and dev-stand process definitions.
- Key files: `systemd/ai_trainer.service` (gunicorn), `systemd/ai_trainer_worker.service` (RQ), `systemd/*.timer` + service pairs (alert, backup, debriefs, reminders, report, summary), `deploy.sh`.

**`docs/`:**
- Purpose: runbooks and design notes. `operations.md` (ops runbook), `exercise_media.md`, `plan-eval.md` (plan rubric), `GATES.md`, `about.md`, `equipment_feature_plan.md`.
- Handoff files: `plan.md`, `memory.md`. Local plans go in `docs/plans/` (gitignored contents).

**`.claude/`:**
- Purpose: agent configuration (permissions, hooks, rules, skills). Versioned, except personal `settings.local.json`.
- Rules with `paths:` in `.claude/rules/` (`python.md`, `templates.md`).

## Key File Locations

**Entry Points:**
- `app.py`: Flask app `app`, gunicorn target `app:app`.
- `tasks.py`: RQ task functions for the worker.
- `cli.py`: CLI commands via `flask --app app <cmd>`.

**Configuration:**
- `config.py`: all env settings, `get_config()`.
- `.env.example`: documented variables (copy to `.env` for dev; never commit real values).
- `ruff.toml`, `pytest.ini`, `.coveragerc`: lint, test, coverage config.
- `migrations/env.py`, `migrations/alembic.ini`: migration config.

**Core Logic:**
- `bp/plan.py`: plan orchestration and plan APIs.
- `ai_generator.py` and `ai_*.py`: AI layer.
- `validation.py`, `validation_options.py`: input rules and options.
- `helpers.py`: shared domain helpers.
- `models.py`: data model.
- `exercise_catalog.py`, `exercise_store.py`: exercise data.

**Testing:**
- `tests/conftest.py`: fixtures (`app` fixture drops and creates tables per test, CSRF off).
- `tests/test_*.py`: unit and integration tests.
- `tests/e2e/`: Playwright.

## Naming Conventions

**Files:**
- Python modules: `snake_case.py`. Feature-split modules use a shared prefix: `ai_generator.py`, `ai_plan_gen.py`, `ai_analysis.py`, `ai_prompts.py`, `ai_normalize.py`, `ai_safety.py`, `ai_quota.py`, `ai_metrics.py`. Option constants go in `validation_options.py`.
- Blueprint modules: named after the feature, `bp/<feature>.py`, with `bp = Blueprint(...)`.
- Tests: `tests/test_<area>.py`; end-to-end tests: `tests/e2e/test_<area>_e2e.py`.
- Templates: `snake_case.html`; partials start with `_`; onboarding steps are `onboarding/step<N>.html`.
- Page JS: `static/pages/<page>.js`, matching the template name where possible (`onboarding_step3.js` for `onboarding/step3.html`).
- Migrations: Alembic-generated `<rev>_<slug>.py`.

**Directories:**
- Lowercase, single word where possible: `bp`, `templates`, `static`, `scripts`, `deploy`.

**Endpoints:**
- `<blueprint>.<function>`, e.g. `plan.my_plan`, `workout.today`. Update `templates/base.html` nav mapping when renaming.

**Data shapes:**
- Plan JSON: `week{N}` → `day{M}` → list of `{exercise, sets, reps, weight, comment}`.

## Where to Add New Code

**New page or route (feature area):**
- Route: add to the matching `bp/<feature>.py`; if the feature is new, create `bp/<feature>.py` with `bp = Blueprint('<feature>', __name__)` and register it in `app.py` next to the other `app.register_blueprint(...)` lines.
- Template: `templates/<page>.html` extending `templates/base.html`, with blocks `title`, `body_class`, `body`, `scripts`.
- Page script: `static/pages/<page>.js` (no inline JS or `<style>`; use `data-*` attributes and delegated listeners in `static/ui.js`).
- Nav: update the active-item mapping in `templates/base.html`.
- Tests: `tests/test_<feature>.py` using the `app` fixture.
- Use the `new-route` skill for the full checklist.

**New API endpoint:**
- Implementation: `bp/<feature>.py` under `/api/...`; JSON errors via `helpers._json_error`; rate limit with `limiter`.
- Tests: `tests/test_api.py` or a feature test file.

**New database table or column:**
- Model: `models.py`.
- Migration: `flask --app app db migrate -m "..."` then `db upgrade`, never hand-written (see the `new-migration` skill).

**New profile option (goal, equipment, limitation, health condition, focus area):**
- Constants: `validation_options.py` first, then re-export via `validation.py` if needed.
- Safety rules: `ai_safety.py`. Prompt wording: `ai_prompts.py`.

**New AI behaviour:**
- Prompt builders: `ai_prompts.py`. Plan generation: `ai_plan_gen.py`. Per-workout analysis: `ai_analysis.py`. Normalisation: `ai_normalize.py`. Client, cache, fallback: `ai_generator.py` only.
- Re-export new public names from `ai_generator.py` so `ai_generator.<name>` stays a valid patch point.
- Long-running calls must go through `jobs.enqueue` with a top-level task in `tasks.py` that imports `app` lazily.

**New background task:**
- Task: `tasks.py` as a top-level function, with `app` and `bp.plan` imported inside the body.
- Enqueue: `jobs.enqueue('tasks.<name>', ...)`.

**New CLI command:**
- `cli.py`, registered on the `cli` blueprint.

**New exercise data:**
- Curated names: `data/ru_catalog.json`; translation overlay: `data/exercises_ru.json`; rebuild seed with `python scripts/build_exercise_seed.py`. Media: see `docs/exercise_media.md`.

**Shared helpers:**
- Cross-blueprint domain logic: `helpers.py` (watch the 600-line limit; split into a sibling module if it grows).
- Pure logic without Flask: a new top-level module (e.g. `report.py` style).

**Utilities and static assets:**
- Shared JS: `static/ui.js`. Feature JS: `static/<feature>.js`. Vendored libraries: `static/vendor/`.
- Images: `static/img/`. Fonts: `static/fonts/`.

**Scripts:**
- Maintenance and build scripts: `scripts/`. Do not add to `scripts/legacy/`.

- Purpose: schema revision history.

**`scripts/legacy/`:**

**`screenshots/agent/`:**

- Generated: Yes. Committed: Yes (`.gitkeep` plus PNGs).
