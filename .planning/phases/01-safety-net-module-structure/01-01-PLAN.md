# Phase 1 Plan 01: Safety Net & Module Structure

## Objective

- **What:** Pin the runtime and dependencies, add the characterization test net, and extract non-route code from the three near-limit modules.
- **Why:** Every later phase changes the AI boundary and the workout flow; without a pinned toolchain and a hard test net those refactors are not detectable before a PROD deploy.
- **Output:** Python 3.12 lockfile-based installs, offline-safe tests for the failure paths, and three modules with at least 100 lines of headroom.
